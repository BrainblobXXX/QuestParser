# Метаданные книги: карточка и провенанс

> Часть инструкции QuestRules. Точка входа — [AGENTS.md](../AGENTS.md).
>
> Поля `game.yaml`, из которых собирается карточка книги в библиотеке и история
> происхождения пакета.

## 1. Назначение

Метаданные отвечают на два вопроса:

1. **что это за книга** — название, автор, жанр, аннотация, обложка;
2. **откуда она взялась** — файл, издание, переводчик, иллюстратор, статус полноты.

Первое видит игрок в библиотеке, второе — человек, который проверяет пакет. Оба
набора живут в `game.yaml`.

## 2. Поля

| Поле | Обязательно | Откуда берётся | Где видно |
|---|---|---|---|
| `title` | да | титульный лист книги | библиотека |
| `author` | нет | титульный лист | библиотека |
| `genre` | нет | обложка, аннотация, предисловие | библиотека |
| `annotation` | нет | обложка или предисловие, 1–3 предложения | библиотека |
| `language` | да | язык текста | служебное |
| `illustrator` | нет | титульный лист, выходные данные | библиотека |
| `translator` | нет | титульный лист, выходные данные | библиотека |
| `edition` | нет | выходные данные | отчёт, провенанс |
| `year` | нет | выходные данные | отчёт, провенанс |
| `source` | нет | файл, URL, название магазина | отчёт, провенанс |
| `status` | да | `complete` или `fragment` | библиотека, отчёт |
| `cover` | нет | обложка книги или первый кадр | библиотека |

Пример:

```yaml
title: Кровь зомби
author: Ян Ливингстон
illustrator: Кевин Кроссли
translator: Андр
genre: фэнтези · книга-игра
annotation: Гингрич Юрр собирается выпустить на волю армию зомби…
language: ru
edition: Fighting Fantasy
year: 2012
source: Кровь зомби (черно-белый вариант).pdf
status: complete
cover: assets/cover.webp
```

## 3. Правила заполнения

- **ничего не выдумывать**: автор, переводчик и иллюстратор берутся только из книги
  или выходных данных; нет данных — поле не пишется;
- отсутствующее поле в интерфейсе показывается прочерком, а не пустотой;
- сомнительное значение (например, на обложке два автора, а на титуле один) —
  запись `C_META_DOUBT` в `review.md` с вариантами;
- `title` — как в книге; если у книги нет названия, ставится рабочее имя пакета и
  это отмечается в отчёте;
- язык перевода и язык оригинала различаются: `language` — язык текста пакета.

## 4. Аннотация

Источники по убыванию надёжности: задняя обложка → предисловие → первый абзац.
Аннотация — это **пересказ издательского текста**, а не реклама от парсера:
1–3 предложения, без оценок и советов. Если аннотации в книге нет, поле не пишется
(или заполняется человеком явно, с пометкой в отчёте).

## 5. Обложка

- `cover` — путь к изображению, обычно `assets/cover.webp`;
- берётся из обложки книги (PDF, скан, файл иллюстрации);
- если обложки нет, поле не пишется; библиотека покажет заглушку;
- обложка не участвует в кадрах сцен: это отдельный ассет.

## 6. Статус и источник

```yaml
status: complete   # полная книга
status: fragment   # ознакомительный фрагмент, см. source.md
```

`source` — человекочитаемая строка: имя файла, ссылка на издание или магазин.
Хэш и дата файла фиксируются в отчёте разбора, в манифест не пишутся.

## 7. Проверки

- `C_META_MISSING` — нет `title`, `language` или `status`;
- `C_META_DOUBT` — данные расходятся между титулом, обложкой и выходными данными;
- `C_COVER_DOUBT` — файл обложки не найден или не открывается;
- `C_SOURCE_FRAGMENT` — статус `fragment`, но маркер фрагмента не найден (или наоборот).

Коды и их уровень — [review.md](review.md).
