# Саундтрек: бриф и музыка

> Часть инструкции QuestRules. Точка входа — [AGENTS.md](../AGENTS.md).
>
> Настроения сцен, формат `soundtrack.md`, правила воспроизведения.

## Музыка как разметка, а не вкус

Раньше настроение выбиралось «на глаз» по описанию сцены, и это давало две проблемы:
бриф расходился с манифестом, а объявленное, но неозвученное настроение незаметно
подменялось запасным треком. Теперь у музыки те же правила, что у иллюстраций:
**цитата-доказательство, сверка брифа с манифестом и машинные проверки.**

## Как выбирать настроение

- настроение ставится **каждой** сцене, даже если трека для него ещё нет;
- выбор — из закрытого списка, ориентиры:

| Ключ | Когда |
|---|---|
| `calm` | осмотр, диалог без угрозы, дорога, развязка |
| `tense` | ожидание, загадка, опасность рядом без действия |
| `danger` | погоня, бой, провал |
| `victory` | находка, спасение, финал |
| `mystery` | странное место, пророчество, сон |
| `grief` | потеря, прощание |

- **настроение выводится из цитаты**, а не из общего впечатления: нужна фраза сцены,
  которая задаёт атмосферу. «Ты замечаешь, что за тобой следят» — цитата для `tense`;
  «Дубинка описывает короткую дугу, и голос умолкает» — для `danger`;
- **нет цитаты — нет настроения.** Сомнительную сцену не размечай «ближайшим»:
  оставь `mood` пустым (тогда продолжается текущий трек) и занеси
  `C_MOOD_NO_EVIDENCE` в `review.md`;
- настроение — это **атмосфера, а не событие**. Нашёл меч — ещё не `victory`, если тон
  сцены спокойный; проиграл бой — `danger`, а не `calm` из-за «ну теперь всё равно»;
- настроений на книгу — 6–8, не больше: частая смена трека утомляет;
- соседние сцены по возможности делят настроение;
- новый ключ не выдумывать: нет подходящего — ближайший плюс запись в `review.md`.

## Формат `soundtrack.md`

Три таблицы, все обязательны:

```markdown
# soundtrack.md

Сцен: 6. Настроений: 4. Треков: 3.

## Сцена → настроение

| Сцена | Название | Настроение | Доказательство |
|---|---|---|---|
| 1 | Глава 1. Вход в пещеру | calm | «Пахнет сыростью и старой золой» |
| 2 | Глава 2. Зал | tense | «За тобой следят» |

## Настроение → главы

| Настроение | Главы | Комментарий |
|---|---|---|
| calm | 1, 3, 5 | осмотр, дорога |
| tense | 2 | сундук |
| victory | 4 | находка |

## Треки

| Настроение | Файл | Готов |
|---|---|---|
| calm | music/calm.mp3 | да |
| tense | music/tense.mp3 | да |
| victory | — | нет, план |
```

- таблица «Сцена → настроение» — **на все сцены**;
- колонка **«Доказательство»** — дословная цитата из этой сцены, по которой выбрано
  настроение; без неё строка не заводится (как «Доказательство» у иллюстраций);
- «Настроение → главы» — сжатые диапазоны (`1–18, 30, 42`), чтобы список читался;
- «Треки» — что уже готово, а что объявлено как план (`null` в манифесте).

## Манифест

```yaml
moods:
  calm: music/calm.mp3
  tense: music/tense.mp3
  victory: null        # настроение объявлено, трека пока нет
default_mood: calm     # только для сцен, у которых настроение не задано вовсе
```

- `null` значит «настроение размечено, музыки ещё нет»; такая сцена **продолжает
  текущий трек**, а не переключается на запасное настроение;
- `default_mood` работает только там, где `mood` у сцены отсутствует полностью;
- у настроения допустим список треков (`tense: [a.mp3, b.mp3]`) — движок выбирает
  случайный при входе в настроение.

## Сверка брифа с манифестом

Таблица «Сцена → настроение» и `scenes.<ключ>.mood` в `game.yaml` — **одно и то же**.
Расхождение (сцена размечена в брифе, но не в манифесте, или наоборот) — `C_MOOD_MISMATCH`.

## Проверки (обязательные)

- у каждой сцены есть `mood`;
- каждый `mood` объявлен в `moods`;
- значение в `moods` — существующий файл или `null`;
- бриф совпадает с манифестом по каждой сцене;
- настроений 6–8;
- у каждого `null` есть запись в `review.md`, что трека пока нет (`C_MOOD_TRACK_MISSING`);
- у каждой строки брифа есть цитата (`C_MOOD_NO_EVIDENCE`).

Пока эти проверки не автоматизированы в движке, конвертер проходит их вручную на шаге
самопроверки и фиксирует расхождения в `review.md`.

## Воспроизведение

Приоритет трека для сцены:

```text
scene.music  →  moods[scene.mood]  →  moods[default_mood]  →  тишина
                 (если настроение задано и трека нет — продолжаем текущий)
```

- смена настроения включает соответствующий трек с кроссфейдом 1,5 секунды; музыка
  зациклена;
- если у следующей сцены `mood` не задан, текущий трек **продолжается**, а не
  обрывается;
- `music` на сцене — разовый трек, приоритетнее настроения;
- `mood` без трека (`null`) — текущий трек продолжается; подмены на `default_mood` нет;
- `default_mood` — только когда у сцены настроения нет совсем: так один готовый трек
  звучит по всей книге, пока остальные ещё в плане;
- воспроизведение стартует после первого действия игрока (браузеры блокируют автоплей);
- выключение звука глушит музыку, гул и щелчки; отдельный переключатель музыки — только
  музыку; при старте другой игры музыка предыдущей останавливается;
- одновременно играет ровно один трек: при быстрой смене предыдущий глушится, а не
  остаётся «осиротевшим» после оборванного кроссфейда.
